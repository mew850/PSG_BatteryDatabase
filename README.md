# 电池测试数据管理平台

一套面向电池课题组的轻量级数据收集、归档、检索与可视化对比系统。  
通过图形化界面实现“规范上传 → 自动归档 → 秒级检索 → 一键对比”，让实验数据从杂乱变为有序。

---

## 主要功能

### 📤 数据上传 (`data_uploader.py`)
- **图形化表单**：自动生成唯一实验ID，动态适配测试类型（循环/EIS/DSC/针刺等），必填项以红色 `*` 标记。  
- **原始文件归档**：支持多文件上传，自动复制至标准化文件夹结构，保留原始数据。  
- **元数据记录**：每批次生成 `experiment_metadata.json` 和 `experiment_info.csv`，并同步至全局 `MasterData.csv`。  
- **智能列名识别**：上传 CSV 时弹出预览窗口，自动检测列名；若缺失则提示用户手动填写或忽略。  
- **自定义测试类型与参数**：支持添加“自定义”测试类型，并通过 `+` 按钮动态增加任意条件参数。  
- **提交人信息**：记录提交人姓名（纳入实验ID）、联系电话、邮箱、小组，以及可选的文章/项目来源。  
- **占位符示例**：所有文本输入框均带有灰色提示文字，聚焦时自动清除，失焦时恢复。

### 🔍 数据检索与对比 (`experiment_locator.py`)
- **多条件模糊查询**：按样品编号、测试类型、开始年月、文件名、**提交人姓名**快速定位实验。  
- **表格化结果展示**：显示实验ID、样品、测试类型、日期、文件名及归档路径。  
- **双击打开文件夹**：直接跳转到归档目录，查看原始数据。  
- **多实验曲线对比**：  
  - 支持 Ctrl/Shift 多选实验，弹出配置对话框，为每个文件独立选择 X/Y 轴列名。  
  - 自动从元数据读取列名，或回退到 CSV 列名。  
  - 绘制期刊风格空心散点曲线，自动处理多 Y 轴（相同坐标轴共用左侧，不同 Y 轴自动添加右侧偏移轴）。  
  - 适用于循环容量衰减、EIS Nyquist 图、DSC 曲线等各类数据对比。

### 📊 模拟数据生成
- `generate_test_files.py`：生成循环性能、EIS、DSC、针刺温度等典型 CSV 测试文件，用于测试系统。  
- `generate_cycle_data.py`：生成严格单调下降的循环数据（放电比容量 vs. 循环号）。  
- `generate_eis_data.py`：生成带半圆和扩散尾的 EIS 频谱数据。

## 安装依赖

```bash
pip install pandas openpyxl matplotlib numpy
```

**可选**：如需生成测试数据，额外安装 `numpy`（已包含在上方命令中）。

## 快速开始

1. **（可选）生成模拟数据**  
   运行任一生成脚本，在项目根目录创建 `TestData_*` 文件夹，内含示例 CSV 文件。

2. **启动数据上传工具**  
   ```bash
   python data_uploader.py
   ```
   在 GUI 中填写必填信息（带 `*`），选择数据文件，点击“提交当前实验”。  
   提交后文件将被复制到 `StructuredArchive/年月/实验ID/raw/`，并在根目录生成/更新 `MasterData.csv`。

3. **查询与对比实验**  
   ```bash
   python experiment_locator.py
   ```
   输入查询条件（如测试类型、提交人姓名），点击“查询”。  
   多选结果行，点击“对比曲线”，在弹出的配置窗口中选择 X/Y 轴，即可生成多轴对比图。

## 数据格式说明

### 元数据 JSON (`experiment_metadata.json`)
```json
{
  "样品编号": "NMC811-C01",
  "测试类别": "耐久性",
  "测试类型": "常温循环",
  "提交人姓名": "张三",
  "列名信息": {
    "cycle.csv": ["循环号", "放电比容量(mAh/g)", "充电比容量(mAh/g)", "效率"]
  },
  "conditions": {
    "循环温度(℃)": "25",
    "充电截止电压(V)": "4.2"
  },
  "出自文章": "ACS Energy Lett. 2024",
  "出自项目": "国家重点研发计划"
}
```

### 全局汇总表 (`MasterData.csv`)
包含样品信息、测试条件、数据文件名、列名信息、提交人等所有字段，每个数据文件占一行。

---

## 注意事项

- 实验ID格式：`YYYYMMDD_样品编号_测试类型_提交人姓名_序号`，例如 `20260722_NMC811-C01_常温循环_张三_01`。  
- 提交人姓名必须填写，并会参与ID生成；若提交后想修改姓名，需重新提交。  
- 列名信息优先从元数据读取，若用户选择忽略则后续绘图时需手动指定。  
- 多轴对比要求所有选中文件的 X 轴列名一致，否则无法绘图。  
- 界面支持连续提交，提交后样品相关字段重置，联系人信息保留。

## 扩展与定制

- 修改占位符示例：编辑 `PLACEHOLDERS` 字典。  
- 调整绘图风格：在 `plot_multi_axis_comparison` 中修改 matplotlib 参数。
